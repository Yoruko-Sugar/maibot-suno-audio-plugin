# Suno 音频工坊

基于 [API Mart Suno API](https://docs.apimart.ai/cn/api-reference/audios/suno/overview) 的 MaiBot 音乐、歌词与音效生成插件。

插件同时支持 `/声音` 指令和自然语言语义触发。生成任务提交成功后立即释放指令/Tool 调用，后台独立轮询供应商；即使音乐需要数分钟，也不会让 MaiBot 的 `cap.call` 一直等待。插件重载后会从独立 SQLite 数据库恢复尚未完成的任务。

## 功能

- 自然语言识别明确的音乐、歌曲、歌词和音效生成意图。
- 使用 MaiBot 已配置的模型优化自然语言，并输出严格的 Suno 参数。
- 保留用户歌词原文，除非用户明确要求改写。
- 支持普通音乐、纯音乐、自定义歌曲、歌词、一次性音效和循环音效。
- 异步提交、后台轮询、重启恢复、状态查询、历史记录和结果重发。
- 支持 URL 文件、Base64 文件和语音消息发送方式。
- 全局管理员、用户/群白名单、冷却、每日额度和并发限制。
- 向其他插件提供异步提交与任务查询 API。

## 安装

1. 将本目录放入 MaiBot 的 `plugins` 目录。
2. 通过插件管理页加载插件。
3. 在配置页填写 API Mart API Key。
4. 在“语义与提示词”中选择一个 MaiBot 当前可用的模型任务。
5. 重新加载插件后发送 `/声音 帮助`。

`config.toml.example` 仅用于查看完整默认值。实际配置由 MaiBot 插件配置系统管理，不要把真实 API Key 提交到仓库。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/声音`、`/声音 帮助` | 以聊天记录形式发送完整帮助 |
| `/声音 音乐 <描述>` | 生成带人声音乐 |
| `/声音 纯音乐 <描述>` | 生成纯音乐 |
| `/声音 歌曲 <标题> \| <风格> \| <歌词>` | 使用指定歌词生成歌曲；歌词可来自引用消息 |
| `/声音 歌词 <主题>` | 只生成歌词 |
| `/声音 音效 <描述>` | 生成一次性音效 |
| `/声音 音效 循环 <描述>` | 生成循环音效 |
| `/声音 音效 高级 <描述> \| <BPM> \| <调性>` | 生成指定速度和调性的循环音效 |
| `/声音 状态 [任务ID]` | 查看任务状态，省略 ID 时查看自己的最近任务 |
| `/声音 历史 [页码]` | 查看当前聊天的任务历史 |
| `/声音 结果 <任务ID> [序号]` | 查看结果详情 |
| `/声音 重发 <任务ID> [序号]` | 重新发送已完成结果 |
| `/声音 管理 队列` | 全局管理员查看待跟踪任务 |
| `/声音 管理 重查 <任务ID>` | 全局管理员立即查询一次供应商状态 |

自然语言示例：

- `帮我生成一首温柔女声唱的夏日城市流行歌`
- `做一段雨夜咖啡馆里的爵士纯音乐`
- `生成一个清脆的游戏升级提示音`

仅当用户明确要求生成时，语义 Tool 才应调用。讨论音乐、询问功能、否定生成、引用或转述别人的请求不会触发。

## 异步任务与计费安全

供应商的生成接口返回 `task_id` 后，插件在后台每隔数秒查询状态。相同来源消息只允许创建一个本地任务，防止规划器重复调用造成重复计费。

如果提交 POST 发生网络中断，插件会将任务标记为“提交结果未知”，不会自动重复提交，因为供应商有可能已经收到了请求。任务状态查询失败可安全重试。

## 对外 API

其他插件可以异步提交：

```python
result = await self.ctx.api.call(
    "maibot-community.suno-audio-plugin.audio_generate",
    operation="music",
    description="温暖的中文城市民谣",
)
```

查询供应商任务：

```python
result = await self.ctx.api.call(
    "maibot-community.suno-audio-plugin.audio_task_get",
    task_id="供应商 task_id",
)
```

对外提交 API 不等待完成，也不自动向聊天发送结果；调用方应保存 `task_id` 并查询状态。
